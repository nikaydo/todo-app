Описание проекта

Это приложение представляет собой простой TODO-менеджер, который позволяет пользователям создавать, редактировать и удалять задачи.

Инструкция по запуску кода локально

1. Убедитесь, что у вас установлен Go версии 1.18 или выше.
2. Все настройки находяться в .env:
3. Запустите сервер командой:
    go run cmd/main.go
    
4. В браузере откройте адрес: `http://localhost:8080`.

Инструкция по запуску тестов

1. В файле `tests/settings.go` укажите следующие параметры:
    FullNextDate = true
    Search = true
    
1.1 Для проверки авторизации и middleware укажите токен в `tests/settings.go` который создаеться при авторизации по http://localhost:8080/login.html
    
2. Запустите тесты командой:
    go test ./tests

Инструкция по сборке и запуску проекта через Docker

1. Соберите Docker-образ
    docker build -t pet_project .

2. Запустите контейнер если хотите удалить контейнер после запуска укажите флаг --rm:
    docker run -p 8080:8080 pet_project

3. В браузере откройте адрес: `http://localhost:8080`.
